# 鼠标躲陨石

一个零依赖、单 HTML 文件实现的 Canvas 生存小游戏。玩家驾驶鼠标飞船，在不断逼近的陨石之间移动、瞄准并跃迁，尽可能获得更高分数。

## 在线游玩

如果仓库已通过 GitHub Pages 等静态托管服务发布，可直接打开对应页面游玩。

## 本地运行

无需安装依赖、无需构建：

1. 下载或克隆本仓库。
2. 用现代桌面浏览器直接打开 [`鼠标躲陨石游戏.html`](./鼠标躲陨石游戏.html)。

也可以在项目目录启动任意静态 HTTP 服务后访问该 HTML 文件；服务不是游戏运行的前置条件。

## 操作方式

- 在登记界面输入玩家名字，点击“开始游戏”。
- 移动鼠标驾驶飞船。
- 按住鼠标左键进入瞄准状态；瞄准期间陨石移动速度降为正常速度的 70%。
- 松开鼠标左键后，若跃迁能量不少于 50，飞船会跃迁到指针位置并消耗 50 点能量。
- 能量会自动恢复；能量不足时松开左键不会跃迁。

## 游戏机制

- 初始舰体耐久为 100，初始跃迁能量为 100。
- 小型、中型和大型陨石会造成不同程度的耐久伤害；受击后会获得短暂无敌时间。
- 收集能量晶体可恢复 5 点耐久并增加 100 分。
- 每收集 5 个能量晶体会刷新一轮晶体。
- 分数越高，游戏难度越高，陨石数量和速度会随之提升；陨石数量最多为 80 个。
- 耐久降为 0 后游戏结束，并显示本局分数和本地排行榜。

## 本地排行榜与隐私

- 排行榜只保存在当前浏览器的 `localStorage` 中，不会上传到服务器。
- 使用的存储键为 `meteorMouseTop3` 和 `meteorMouseLastPlayer`。
- 同名玩家只保留最高分，排行榜按分数降序保留前三名。
- 排行榜展示时会对姓名脱敏，但浏览器本地仍保存原始姓名以支持同名合并。

## 项目结构

```text
.
├── 鼠标躲陨石游戏.html      # 当前权威版本：HTML、CSS、JavaScript 均内嵌
├── 鼠标躲陨石游戏_v2.html    # 历史快照
├── 鼠标躲陨石游戏_v3.html    # 历史快照
├── 鼠标躲陨石游戏_v4.html    # 历史快照
└── AGENTS.md                # 项目协作与验收约定
```

带 `_v2`、`_v3`、`_v4` 后缀的文件仅用于保留历史版本；日常运行和修改请以无后缀的 `鼠标躲陨石游戏.html` 为准。

## 技术特点

- 原生 HTML、CSS、JavaScript 和 Canvas 2D API。
- 无框架、无第三方依赖、无构建步骤。
- 使用浏览器 Web Audio API 提供受用户交互触发的音效。
- 适合直接部署到 GitHub Pages 等静态文件托管服务。

## 兼容性说明

建议使用较新的 Chrome、Edge、Safari 或 Firefox 桌面版浏览器，并允许页面响应鼠标指针事件和音频上下文。游戏需要用户点击“开始游戏”后才会解锁音效。
